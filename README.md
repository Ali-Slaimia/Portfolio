# Portfolio

Personal portfolio — Full-stack & AI software engineer. React, Angular, Spring Boot, ML. Open to roles in Europe & Tunisia.

Built with Next.js and Tailwind CSS.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize everything in one file

Edit **`src/data/portfolio.ts`** — your name, bio, projects, skills, experience, and links.

## Deploy (free)

1. Push to GitHub.
2. Import the repo on [Vercel](https://vercel.com).
3. Deploy — no config needed.

## Build for production

```bash
npm run build
npm start
```
